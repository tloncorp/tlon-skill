# Tlon Skill

>

## What was this?

A CLI tool for interacting with Tlon/Urbit APIs — activity, channels, contacts, groups, messages, DMs, posts, and more.

## Installation

The package continues to be published from the monorepo:

```bash
npm install @tloncorp/tlon-skill
```

## Documentation

See [`packages/tlon-skill`](https://github.com/tloncorp/tlon-apps/tree/develop/packages/tlon-skill) in the monorepo for the current README and full command reference.
